# 投资人两题 · 定稿说明

> 生成日期：2026-09-05
> 适用场合：投资公司/投资人通用问卷（无字数限制）
> 项目：ForgeLingo（pre-seed）

---

## 两道题

1. 请简单描述一下在你童年、少年、青年时期成长过程中对你影响最大的几件事情和经历
2. 你的一技之长是什么？别人会在何种情况下或哪些方面向你寻求帮助？

## 三个倾向怎么选

| 版本 | 重心 | 适合谁 | 风险 |
|---|---|---|---|
| **一 · 克制**（事实驱动） | 事件 → 决策 → 结果。无形容词、无口号 | 传统机构、财务型投资人、要归档进尽调材料的书面场合 | 读起来偏冷，不容易让人记住你这个人 |
| **二 · 锋芒**（观点驱动） | 先下结论再举证，敢说非共识判断 | 早期、看人、专门找"比别人多看一两步"的投资人 | 遇到保守型的人会觉得太满、太硬 |
| **三 · 真诚**（人性驱动） | 保留脆弱、代价和边界，讲驱动力从哪来 | 天使、个人投资人；也最适合面对面讲 | 情绪比重高，遇到只看数据的人会觉得偏软 |

**两题必须用同一个倾向。** 第一题用锋芒版、第二题用真诚版，读起来会像两个人写的。

## 投资人问这两题到底在测什么

调研结论（来源见文末）：

| 题目 | 表面在问 | 实际在测 |
|---|---|---|
| 童年/少年/青年 | 你的故事 | **动机的耐久性**。建一家公司要 7–10 年，这题是最便宜的 authenticity probe：测你的驱动力是真实长出来的，还是为融资反推出来的 |
| 一技之长 + 谁来找你 | 你的技能 | **founder-market fit / unfair advantage**。为什么是你；"谁在什么情况下找你"是让别人替你背书，比自评可信 |

陆奇公开讲过的创始团队五维度：独立思考（比别人多看一到两步）、行动导向、价值需求导向、沟通能力、持久内在驱动力。

写法要点：
- **简洁本身是信号**。YC 内部反馈原话：表达得多简练是评判答案好坏的重要指标，光是做过很酷的事不够。
- **可以写不正面的经历**，只要真实、且能解释驱动力。套路化的励志模板反而扣分。
- **叙事必须连贯**：经历 → 塑造了什么特质 → 这个特质解释了你现在为什么这么做。
- **别道歉，要解释**：不为背景缺口道歉，而是说清这条路为什么把你准备成了现在这个人。
- **证据要产出型**（做过什么），不要消费型（读过什么）。

## Claim boundary 核对（第二题）

三个版本都过了同一道检查，依据 `Projects/forgelingo/docs/2026-08-02-product-lineage-and-terminology-boundary.md` 与 `research/2026-07-29-forgelingo-preseed-product-data-thesis.md`：

| 规定不能说的 | 三版有没有说 |
|---|---|
| 官方 NAATI/CCL 或 PTE 产品、官方分数等价 | 没有；第三点主动否认 |
| 跨考试/跨语言评分已验证 | 没提 |
| 模型准确率、通过率、用户数、收入、转化 | 一个数字都没有 |
| 训练级数据集、拥有或可自由训练录音 | 没有；写成"门槛"而非"已完成" |
| "通用 assessment engine 已完成" | 只描述自己代码的分层方式，未用"通用""已完成" |
| 更大的"AI 语言评估平台"框架 | 回避；用 memo §1 自己批准的 pre-seed 定位措辞 |

**特意软化的一处**：consent 在 memo 里是尚未完成的第一道 evidence gate，所以写成"把它设成了自己的第一道验证门槛"，不是"已经做好了"。做完之后可改成完成时。

## 交之前自己做的两件事

1. **把第一题第一段念出来。** 念得下来就留着，念着卡就删——写进去意味着面谈时会被追问一遍。
2. **确认渠道。** vault 里 ForgeLingo 的融资状态是 parked，且对中投华创那类付费路演渠道设了"付款前全数通过门槛"。如果这两题从那个渠道来，先对一下自己定的门槛。

## 大概率会被追问的三点

- **"没有证据就不扣分——怎么保证模型真的守这条？"** → 讲 golden set + 人工复核，诚实说这是下一笔钱要证明的事。
- **"分层这件事，除了 CCL 你验证过第二个吗？"** → 按自己的 claim ledger，答案是还没有，第一个相邻 adapter 是下一个 gate。**直说，别含糊。**
- **"那你的护城河是什么？"** → 不在录音本身，在于输入、输出、评分证据、后续行为能否被可靠对齐和审查。
