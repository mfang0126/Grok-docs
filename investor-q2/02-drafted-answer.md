# 第二题：一技之长 + 别人何时来找你（最终答案）

我的一技之长是技术嗅觉——别人还在追热点的时候，我已经在拆架构了。

从小学开始，家里买手机、买电脑都问我为什么买、配件怎么配、机箱怎么组装。别人有技术问题就找我：装系统、修故障、配游戏机。这个习惯一直没断。

后来我看了十几年苹果发布会，读乔布斯、John Ive、马斯克的自传，也读了大量心理学和思考类的书。这些让我能快速判断一个技术的走向。

比如ChatGPT刚出来时，我就判断Chatbot会死，重点会转向垂直领域的能力分析。后来bot出来了，我又判断未来每个人都会有不同的assistant，价格会无限降低。Grok用动态启动小实例、按需开关，把使用时间算进成本——这个逻辑我一看就明白，因为我自己也在做类似的harness。

别人来找我，通常是两种情况：一是新的技术出来，没人知道它会怎么走，需要我判断方向；二是卡在一个代码问题上没人能解，需要我拆开它。

我验证完之后会主动动手，喜欢做创造性的事，也喜欢追新的东西。这是我的习惯，不是性格。
