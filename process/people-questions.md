# 投资人「投人题」怎么想、怎么聊、怎么收

给下一次的自己，也给要帮别人做同类题的人。
这份文件只记方法，不记某个人的故事细节。

---

## 0. 这类题到底在问什么

早期没有足够的数据可算。投资人问童年、一技之长、为什么是你，都是在测同一件事：

> 这个人在没人看的时候，会怎么做决定。

表面问题 | 实际在测
--- | ---
童年 / 少年 / 青年 | 动机是不是长出来的，还是为融资反推的
一技之长 + 谁来找你 | 不公平优势有没有被别人用过
为什么做这个 | founder-market fit，不是赛道热
最大的失败 | 自知和修正能力

两道相关题必须同一条弧线、同一个语气。一题锋芒、一题柔弱，读起来像两个人。

---

## 1. 怎么交流（比怎么写更重要）

### 角色

- 被采访人：只负责倒素材。不要边讲边把自己写成答案。
- 协助人：只负责问、记、筛、压。不要替他编一个更好看的人。

### 对话规则

1. **先定读者，再开口。** 谁在读、书面还是面谈、有没有字数。再选一个倾向：克制 / 锋芒 / 真诚。
2. **先采集，后写作。** 倒素材的那一轮，禁止出成稿。
3. **要画面，不要标签。** 「那天坐绿皮车」可用。「我很有安全感 / 格局 / 前瞻性」不可用。
4. **分清时态。** 当时只是觉得不对劲，还是现在回看才明白。后者可以当洞察，不能当当时的事实。
5. **协助人不要审问。** 追问「你能证明吗」会让对方防御，素材会停。要问的是「当时的画面是什么」「这个习惯后来的代价是什么」。
6. **被采访人可以打断。** 一旦觉得跑题了，直说「回题」。协助人必须停下重新对齐。

### 开场口令（直接复制）

> 这题测的是动机还是能力？
> 先倒素材，这一轮不写答案。
> 筛完只留三个锚。
> 用已经选好的倾向出一版。

## 2. 怎么想（从素材到答案）

### 步骤

```
定读者 → 按阶段倒素材 → 用四问筛 → 写因果链 → 留三个锚 → 成稿 → 念出来 + 追问预演
```

一步不完，不进下一步。

### 筛素材的四问

一条过不了就进附录，不进答案。

1. 它解释了你现在怎么做决定吗？
2. 有没有一个别人能看见的画面？
3. 有没有代价？只有优势的故事当成功学。
4. 是产出型（做过、别人找过）还是消费型（读过、看过、想过）？

### 因果链（必填）

> 发生了什么 → 我当时怎么做 → 这变成什么习惯 → 这个习惯的代价 → 我现在怎么改

缺一截就还不是答案。

### 成稿只留三个锚

每题最多三个画面。再多就是流水账。
三个倾向可以后补，不要第一轮就写三版。

## 3. 文件怎么放

每一题一个目录：

```
qX/
  01-raw-details.md     采集区，敢乱、分阶段、标出「不进答案」
  02-drafted-answer.md  单一倾向的第一版成稿
final/
  00-how-to-choose.md   读者和倾向怎么选
  qX-three-versions.md  需要换读者时才写
```

私人细节只进私有仓库。不要写进公开项目。

---

## 4. 交之前的两道检查

1. **念第一段。** 念着卡、或不愿被当面追问的细节，删。
2. **Claim 边界。** 没验证的当门槛写，不当结果写。没有的数字、官方等价、用户量、准确率，一律不写。

预演追问，不预演演讲。每题准备一句话能答完的跟进，且不和成稿打架。

---

## 5. 上次踩过的坑（下次直接跳过）

- 把「投资人要什么」辩太久。定一次就够，写进本文件第 0 节。
- 用履历标准审问对方。对方会停止供给素材。
- 边听边写成稿。素材还没稳，成稿一定偏。
- 把「我知道得早」当成能力。能力是动过手、有人来找过。
- 用读过的书、看过的会当证据。
- 两题换语气。
- 私人细节写进公开仓库。

---

## 6. 流程能管什么，管不了什么

能管：采集顺序、筛选标准、成稿结构、语气一致、claim 边界、存档位置。
管不了：哪一段是真转折、语气选哪一档、个人故事怎么接上项目。

流程是质检，不是灵魂。
